Поля/колонки: inventory_number, model (ключ модели, например geoscan-201), необязательно base_launch_site, location_lat/location_lon (WGS-84 — где сейчас стоит БВС, у разных экземпляров могут отличаться), status (по умолчанию «Готов»).
