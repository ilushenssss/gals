Загрузка обстановки

GeoJSON — FeatureCollection со свойством layer у каждого объекта: launch_site, airspace, no_fly, obstacle, reserve_site. KML — зоны ограничений (высота и релевантность БВС определяются автоматически) и высотные препятствия (экструдированные 3D-объекты).

Новый парк БВС

Поля/колонки: inventory_number, model (ключ модели, например geoscan-201), необязательно base_launch_site, status (по умолчанию «Готов»), location_lat/location_lon (WGS-84, координаты конкретного БВС). Широта и долгота базы парка вручную не вводятся — они вычисляются по координатам экземпляров из этого файла (нужен хотя бы один экземпляр с указанной локацией) и используются для проверки совместимости парка с обстановкой при постановке задачи.
